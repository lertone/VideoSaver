使用指引：功能、支持范围与限制

一、这是什么

一个只在自己电脑上跑的视频保存工具。界面在浏览器里打开，实际干活的是本机的 127.0.0.1:8765 服务：用 yt-dlp 去取视频，用 ffmpeg 处理画面。 文件和登录信息都留在你自己的硬盘上，不上传任何服务器，别人也访问不到这个页面。

二、功能一览

环节能做什么
输入粘贴链接，或整段分享文案（会自动把里面的网址挑出来）；jingxuan?modal_id= 这类会整理成标准链接后再解析。
画质默认 / 4K / 1080P / 720P / 480P / MP3 六档，另可选帧率（高帧率优先 / 省体积）与下载速度。抖音/快手为平台源文件，画质由原片决定。
网络自动找本机代理、手填地址、完全直连；可配多个备用地址，按网站固定 / 轮流 / 随机；失败自动换一个重试，全不通再回退直连。
登录信息四种来源：自动匹配文件、只用文件、从浏览器读、完全不用。支持插件导出的 JSON、txt 文件、直接粘贴 Cookie 文本。
过程实时日志给出百分比、速度、剩余时间。换链接会先中断上一个任务，不会卡在「下载中」。
文件卡片式列表，按 视频 / 音频 / 图片 / 文本 分类筛选；视频与图片显示缩略图，文本可直接预览正文。改名、送进系统回收站（可在资源管理器还原）、在资源管理器里定位、另存到本机。
图文笔记小红书图文笔记会保存全部图片（jpg）＋正文（txt）；微博图文需要一份 weibo.com 的登录信息，导入后同样保存图片＋正文。抖音图文暂不支持（只有图片，没有视频流）。
拖着用支持从资源管理器把文件拖进窗口，自动导入当前保存文件夹；拖到「常用路径」上的某条路径 = 移动过去。受 WebView2 限制，不能把文件直接拖出窗口，放到桌面请用「另存」。
联网搜索（可选）让 AI 能「自己找视频」：设置 → 联网搜索，选供应商并填自己的 Key。博查 / Tavily / Serper 都有试用或免费额度、之后按量计费；自建 SearXNG 完全免费。不填 Key 时 AI 会如实说「未启用」，不会编链接。
SearXNG 部署要点① 2 核 2G 够用（本体只占 100~200MB，瓶颈在上游引擎限流）；② 也可以部署在自己电脑上：装好 Docker Desktop 后，在设置 → 联网搜索 → 选 SearXNG →「一键部署 / 启动」即可（自动拉镜像、写配置、起容器、回填地址，全程不用终端）；③ 必须在 settings.yml 里把 search: formats 加上 json（默认只有 html，否则本工具请求会 403）；④ 国内服务器建议只启用 bing / baidu / 360 / sogou，关掉 google / duckduckgo，否则每个引擎都要等超时。
怎么真正退出关窗口只是收进托盘（图标在任务栏右下角的 ^ 里），程序仍在后台跑。要彻底关掉：设置 → 退出 → 彻底退出 VideoSaver，或右键托盘图标 → 退出。
AI 助手右上角「AI 助手」：模型由你自己提供（默认智谱 GLM-4-Flash），能帮你查报错、解释术语、找文件、改保存目录、直接开始下载。Key 只存在本机配置文件里，界面和日志都会打码。
预览独立浮窗，可同时开多个（顶部标签切换，标签过多自动压缩，鼠标中键关闭）；拖动标题栏移动、右下角改大小、— 收起。不遮挡主界面，可一边播一边操作。
主题顶栏右侧的太阳/月亮药丸开关就是主题开关：拖动圆钮或点一下，整套配色逐帧过渡、松手弹到最近一端。两套主题各配一款悬浮岛与悬浮球（月亮=近黑玻璃+月牙，太阳=白玻璃+日轮）。要回原来的深灰蓝：设置 → 外观主题 →「回到经典主题」。
音频毛玻璃悬浮岛：上一首 / 播放暂停 / 下一首、单曲循环·列表·随机、可拖进度条、实时心电图波形；点波形缩成悬浮球，再点展开。按住波形或标题可直接拖动。
去水印框选区域 / 预设角落 / 自动猜位置；先出 5 秒样片确认效果，满意再处理整段；原片保留，结果另存新文件。
轻量增强预览窗右下角「轻量增强」：降噪 →（可选）2× 放大 → 提锐，同样先出 5 秒样片；进度写在「进度记录」里。只改善噪点与边缘观感，不会凭空生出细节，480P 放大到 960P 也不会变成真高清。体积上默认档约原片 1.4 倍，开 2× 约 2.3 倍，耗时同步上升。
更新设置里可一键把解析引擎（yt-dlp）升到最新版；先下载到临时文件、跑通版本校验再替换，失败自动回滚。
运行方式独立窗口，没有浏览器地址栏和标签页。关闭窗口会收进右下角托盘，正在进行的下载不中断；托盘菜单可重新打开窗口、打开保存文件夹、彻底退出。

三、支持哪些网站

解析引擎是本机安装的 yt-dlp，当前版本内置 1600+ 个站点提取器，覆盖绝大多数公开视频站点。 点右上角「支持站点」可以按关键词搜索（如 youtube / bilibili / ins）； 「实测可用」指在本工具里真实下载成功过，其余是引擎支持但没逐个验证。

平台情况说明
B 站实测可用未登录 / 非大会员最高只有 852x480（480P）；720P 准高清、1080P+、4K 都是大会员权益，会提示 premium member only。登录信息解决的是风控与登录可见内容，不是画质。
YouTube一般可用被要求「确认你不是机器人」时填登录信息；高级里播放器标识填 ios,web_safari 有帮助。
快手实测可用支持 short-video / photo 页和 v.kuaishou.com 短链，移动端直链解析，无需登录、无需解析服务；实测 3-4MB/s。
腾讯视频（免费内容）可下 · 看网速走 HLS（N_m3u8DL-RE 下载，分片临时文件不落进下载文件夹）；会自动实测各 CDN 线路挑最快。腾讯对非浏览器拉流限速，慢时会自动提示并终止。
小红书、微博引擎原生支持视频笔记与微博视频可直接下；小红书图文笔记会保存全部图片 + 正文 txt。短链（xhslink.cn）自动展开；部分内容需要登录信息。
Vimeo、Dailymotion、多数新闻 / 播客 / 公开课引擎支持未逐个实测，一般直接可用。
Twitter/X、TikTok 公开视频多数可用敏感、私密、地区限制的内容需要登录信息。
Instagram基本要登录不登录通常只给低清，或直接拒绝请求。
抖音需自建服务分享页带设备指纹，本地引擎算不出签名。在【设置 → 抖音解析服务】填上自建 DTK 服务的地址和 API Key 后即可下载（可拿到无水印直链）；不填则失败。
Netflix、Disney+、爱奇艺、优酷 会员片 / 腾讯会员片永不支持DRM 加密，属技术性不可解，不是配置问题。

四、已知限制

  1. 抖音要靠外部解析服务。抖音在分享页加了设备指纹（UIFID，由浏览器 JS 生成），本地请求伪造不出来，所以本地引擎一定失败——这跟你填不填登录信息无关。解决办法是接一个自建服务（开源项目 Evil0ctal/Douyin_TikTok_Download_API，简称 DTK）：它复现了 a_bogus 签名和浏览器 TLS 指纹。在【设置 → 抖音解析服务】填地址 + API Key 即可，本工具拿它给的无水印直链再下载。
  2. 登录信息只证明「你是谁」。它不能把没买过的画质给你——大会员 4K 仍要求账号本身有权限。
  3. Chrome / Edge 127 之后把登录信息加密锁住了，程序读不出来，只能导出成文件导入。Firefox 无此问题。
  4. 去水印与轻量增强都是整段重新编码，不是简单裁剪：耗时长，成片体积也可能比原片更大。增强只能减噪、提锐、轻微放大，不能提高真实清晰度上限。
  5. 服务只监听 127.0.0.1，同一局域网的手机、平板也访问不到，这是刻意的安全设计。
  6. 微博图文要登录信息。微博的图文接口要求登录态，导入一份 weibo.com 的 cookies.txt 后会自动保存图片＋正文；没导入时日志会明确提示，不会假装成功。
  7. 抖音图文不支持。抖音图文只有图片、没有视频流，本地引擎和 DTK 都只解视频；这类链接会在日志里直接说明。
  8. 站点的风控会随时间变化。今天能下的站点，明天可能要求验证；同一份链接用久了被要求登录，属正常现象。

外部解析服务（抖音 / 小红书）

这是什么？点开看说明
抖音分享页带设备指纹（UIFID），本地引擎算不出签名，所以要接外部解析服务。 B站继续用登录 Cookie；小红书可以走 Tikhub（单文件，免服务器）。 （开源项目 Evil0ctal/Douyin_TikTok_Download_API）拿无水印直链。
不填也能下别的网站，只是抖音会失败。
自建 DTK / 网关 / Tikhub 托管都支持。地址填根地址（如 http://IP:8000 或 https://api.tikhub.io），不要带 /api/...。 测服务返回 501 / 网页，说明填成了静态服务器或前端端口。
怎么接？两种方案，步骤写全了

方案 A：Tikhub 托管（普通人推荐，免服务器）

  1. 注册 tikhub.io， 在用户中心 → API Keys 创建一个 Token。
  2. 上面「服务类型」选 Tikhub 托管；地址填 https://api.tikhub.io； Key 填 Tikhub 的 Token（不是 dtk_ 开头）。
  3. 保存后粘一条抖音链接试。Tikhub 是按量计费，注册一般有试用额度， 不适合完全零成本；余额/权限问题会返回 401/402/403。

方案 B：本机跑 DTK（免费，不用买服务器）

  1. 装 Docker Desktop（Windows / macOS）或 Docker Engine（Linux），Compose v2.24+ 会一起装。普通用户本机跑就够，不需要买服务器；服务器只是可选，适合 24 小时挂机或多设备共用。
  2. 拉代码 
    git clone https://github.com/Evil0ctal/Douyin_TikTok_Download_API.git
cd Douyin_TikTok_Download_API
  3. 准备配置 
    cp .env.example .env
    打开 .env，至少填 DTK_SECRET_KEY（随机长串）、 POSTGRES_PASSWORD、REDIS_PASSWORD。密码别用默认值。
  4. 启动 
    PowerShell：
$env:COMPOSE_ENV_FILES=".env"; docker compose -p dtk -f docker/compose.yml up -d --wait --wait-timeout 300

macOS / Linux：
COMPOSE_ENV_FILES=.env docker compose -p dtk -f docker/compose.yml up -d --wait --wait-timeout 300
    等所有容器 healthy；docker compose -p dtk ps 可以看状态。
  5. 本机用：保持 127.0.0.1:8000 就行，不用改防火墙。 要给别的设备用，再把映射改成 0.0.0.0:8000 并放行端口； 或者放服务器/挂 Nginx。不要把 8000 裸奔到公网还不设 Key。
  6. 创建 API Key：浏览器打开 http://127.0.0.1:8000 控制台， 在 API Keys 页面创建一个 dtk_ 开头的 Key。
  7. 回到这里：服务类型选 自建 DTK / 网关；地址填 http://127.0.0.1:8000（根地址，不要带 /api/...）；Key 贴进去； 点「测一下服务通不通」，通过后保存。
  8. 第一次解析：在控制台/身份池放一个已登录的抖音 Cookie，成功率和画质会更高。 本机不用导入抖音 Cookie。

方案 C：只下 B 站 / 小红书

不需要抖音解析。到「网站登录信息」导入对应站点的 Cookie 即可。 画质取决于账号/VIP（B 站 1080P 要登录、4K/HDR 要大会员）， 水印取决于平台和作者，不能保证去掉。抖音的 fresh_cookies 不是 Cookie 问题，必须走上面的解析服务。

报错对照：
501 / 返回网页 = 填了静态网页或前端端口，不是 API；
401 = Key 无效/过期；
403 = Key 没有对应平台的权限，或服务端没开这个站点；
404 = 路径不对，通常是把 /api/... 也填进了地址。

解析引擎（yt-dlp）

为什么要更新？
各站点风控规则常变，隔段时间更新一次，否则会出现「以前能下、现在下不动」。 更新只替换 bin/yt-dlp.exe，失败自动回滚；已是最新版会自动跳过，不会重复下载。
